LKH 3.0.14 by Keld Helsgaun
https://webhotel4.ruc.dk/~keld/research/LKH-3/
Private research use. The author reserves all rights to the code.
The Finland profile contains the parameters used for BD's Finland comparison.
The licensed binary is encrypted using the existing protected app envelope.
Runtime bridge: compile stock LKH with the Carbon glue, import C transcendental
functions from the browser Math implementation, verify solutions independently.

GA-EAX 1.0 Normal by Yuichi Nagata (MIT, gaeax/LICENSE.txt)
Source: https://github.com/nagata-yuichi/GA-EAX/tree/015dfbe9f267230f78787bd244af393ffc018900/GA_EAX_1.0/Normal
Browser glue: tests/fixtures/tsp-rivals/gaeax-web.cpp in the site repository.
Built using Emscripten 4.0.23. The adapter calls the upstream crossover, local
search, survivor selection and stopping rules with a browser deadline.

Google OR-Tools Routing (Apache-2.0, ortools/LICENSE.txt)
https://github.com/google/or-tools
Bundled browser Routing runtime by Axel Wickman from or-tools-wasm 2.2.0.
https://github.com/Axelwickm/or-tools-wasm/tree/v2.2.0
Pinned upstream runtime files under ortools/. Only the browser Routing modules
are included. The app submits a single vehicle with a rounded EUC_2D matrix.

Concorde 03.12.19 by David Applegate, Robert Bixby, Vašek Chvátal, and William Cook.
https://www.math.uwaterloo.ca/tsp/concorde/downloads/downloads.htm
For academic research. The solver is available only within the protected app.
The browser adapter uses the original branch-and-cut solver with QSopt_ex
(April 2009, research-use terms) and GMP 6.3.0 (LGPL-3.0-or-later).
https://www.math.uwaterloo.ca/~bico/qsopt/ex/
https://gmplib.org/download/gmp/gmp-6.3.0.tar.xz
Runs locally on EUC_2D inputs, 5–3,500 cities. Tours and proof status are
reported separately. Browser build materials and relinkable objects can
be requested from the site operator.
