Kaj je tu in česa niWhat is here and what is not

  • Samo BD-jevi osebni projekti in projekti AI8. Koda, povezana s službo, ni vključena.
  • Trgovalni projekti so navedeni z imenom, kratkim opisom namena in številom vrstic. Parametri, pravila vstopa in izstopa, strategije, formule, nastavitve in izseki kode so zasebni.
  • Poti so relativne glede na repozitorij. Brez e-poštnih naslovov, IP naslovov, uporabniških imen in lokalnih absolutnih poti.
  • Povezave do posameznih datotek bodo na voljo ob objavi repozitorija.
  • Dodatne datoteke, ki že živijo v svojih repozitorijih BD-Chess, so štete posebej in tu niso naštete.
  • Only BD's personal projects and AI8 projects. Code related to his employment is not included.
  • Trading projects are listed with name, a short description of purpose and line count. Parameters, entry and exit rules, strategies, formulas, settings and code excerpts stay private.
  • Paths are relative to the repository. No e-mail addresses, IP addresses, user names or local absolute paths.
  • Links to individual files will be available when the repository is published.
  • Extra files that already live in their own BD-Chess repositories are counted separately and not listed here.
