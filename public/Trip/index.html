    Why 8Z-RP?

    Deterministic Results: Unlike many online solvers that produce random variations every time you click, 8Z-RP guarantees Same Input ⇒ Same Route.

    Deep Search: The "Deep Search" mode runs the optimization algorithm 12 times in parallel to find the absolute shortest path.

    How to Use

    • 1. Presets: Use the dropdown to load a famous trip (e.g., Paris, California).
    • 2. Edit: Add or remove stops in the text box.
    • 3. Save/Load: Use the 💾 and 📂 buttons to keep your plans safe.
    • 4. Optimize: Click "Standard" or "Deep Search".

    Input Formats

    You can mix and match these formats.

    1. GPS Coordinates (Recommended)

    46.0569, 14.5058

    2. Addresses / Place Names

    Tivoli Park, Ljubljana

    3. Custom Name with GPS

    Home | 46.0428, 14.4500

    Locking the Start
