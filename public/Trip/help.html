How to Use

  • 1. Enter Locations: Type your stops in the text box. One per line.
  • 2. Optimize: Click "Fast" for quick results or "Balanced" for a deeper search.
  • 3. View Route: The map will draw the path. The stops are reordered efficiently.
  • 4. Export: Click the "Open in Maps" buttons to send the route (or specific legs of it) to Google Maps on your phone.

Input Formats

You can mix and match these formats in the input box.

1. GPS Coordinates (Recommended)

Most precise. No internet lookup required.

46.0569, 14.5058

2. Addresses / Place Names

The tool will use Google to find these coordinates automatically.

Tivoli Park, Ljubljana
Prešernov trg, Ljubljana

3. Custom Name with GPS

Useful for "Home" or specific meeting points.

Home | 46.0428, 14.4500
Meeting Spot | 46.0510, 14.5051

Special Commands

Locking the Start

By default, the optimizer might change your starting point to find the shortest loop. To force a specific location to be the start, add the word START anywhere on that line.

Grand Hotel Union | 46.0525, 14.5060 START

Comments

Lines starting with # are ignored. Use them for notes.

# This is my trip to Ljubljana
Tivoli Park, Ljubljana

Troubleshooting

  • "Geocode failed": The tool couldn't find the address. Check for typos or try adding the city name (e.g., "Main St, London").
  • "ApiNotActivated": Your API Key is missing permissions. Go to Google Cloud Console and enable the "Geocoding API".
  • Map looks grey/dark: Ensure you have enabled "Maps JavaScript API" in your Google Cloud Console.
