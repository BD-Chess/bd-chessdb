    How to Use

    • 1. Enter Locations: Type your stops in the text box. One per line.
    • 2. Optimize: Click "Fast" for quick results or "Balanced" for a deeper search.
    • 3. View Route: The map will draw the path. Toggle between "Driving" and "Direct Lines".
    • 4. Export: Click the "Open in Maps" buttons to send the route to your phone.

    Input Formats

    You can mix and match these formats.

    1. GPS Coordinates (Recommended)

    46.0569, 14.5058

    2. Addresses / Place Names

    Tivoli Park, Ljubljana

    3. Custom Name with GPS

    Home | 46.0428, 14.4500

    Special Commands

    Locking the Start

    Add START anywhere on a line to lock it as the starting point.

    Grand Hotel Union | 46.0525, 14.5060 START

    Troubleshooting

    • "Geocode failed": Check spelling or add city name.
    • Map Errors: Ensure your API Key has "Maps JavaScript API", "Geocoding API", and "Directions API" enabled.
