Kako brati primerjavo

AI8 je relativna, utežena ocena metaindeksa (0–100), ne odstotek pravilnih odgovorov. Število virov in pokritost se razlikujeta; majhne razlike niso zanesljiva razvrstitev. Klik na številčni stolpec spremeni vrstni red. Izbira modela spremeni vse ocene v vrstici.

Spletni klepeti lahko uporabljajo drugačen model, nastavitev, orodja ali naročniški paket, kot so bili uporabljeni na testih.

Kaj merijo stolpci

Arena: človeška preferenca (Elo); AA Code: FrontierCode 2.0 (%); Epoch GPQA: zahtevna vprašanja (%); ARC: abstraktno sklepanje (%); Terminal: agentne terminalske naloge (%). To so različne lestvice, zato številk med stolpci ne seštevamo.

API povezave vodijo na uradne razvojne strani. Pri Copilotu gre za API družine Microsoft 365; Meta API ni nujno enak modelu v klepetu. Za Dolo javnega API-ja nismo potrdili.
