LLM meta indeks — kateri model je res najboljšiLLM meta-index — which model is really the best

Ena lestvica ne pove dosti: vsaka meri nekaj drugega, nekatere so zastarele, nekatere vodijo prodajalci podatkov. Meta indeks zato združi 33 uglednih virov (144 lestvic) v primerljivo oceno za 203 modelov, od tega jih je 150 rangiranih.

A single leaderboard says little: each measures something different, some are stale, some are run by data vendors. The meta-index therefore combines 33 respected sources (144 boards) into one comparable score for 203 models, 150 of them ranked.

  • Normalizacija: vsaka lestvica se pretvori v percentilni rang 0–100 med modeli v indeksu (100 = najboljši, 50 = sredina). Nato se popravi za moč polja (prvo mesto na stari lestvici s starimi modeli šteje manj kot prvo mesto med najnovejšimi) in uteži po ugledu vira, svežini in pomenu. Skupna ocena je tehtano povprečje kategorij.
  • Ocene so relativne, ne absolutne. Razlika nekaj točk na vrhu je manjša od negotovosti metode, zato prvih pet beri kot skupino, ne kot strog vrstni red.
  • Večinoma pri največjem naporu: pri vsakem modelu šteje njegova najboljša nastavitev na posamezni lestvici, običajno max/xhigh razmišljanje. Hitrejše ali cenejše nastavitve istega modela so lahko precej slabše.
  • Cene so na žeton, ne na nalogo (USD na 1 M žetonov, vhod/izhod, standardni cenik). Modeli, ki veliko razmišljajo, porabijo več žetonov in so v praksi dražji, kot kaže tabela. Vrednost = skupna ocena ÷ mešana cena (3 : 1 vhod : izhod).
  • Zaupanje = število neodvisnih virov (visoko ≥ 6, srednje 3–5, nizko ≤ 2). Rangiran je le model z vsaj 3 viri in pokritostjo kategorij vsaj 45 %.
  • Normalisation: every board is turned into a percentile rank 0–100 among the models in the index (100 = best, 50 = middle). It is then corrected for field strength (1st place on a stale board of old models counts less than 1st place among the newest ones) and weighted by source respectability, freshness and relevance. The overall score is a weighted mean of the categories.
  • Scores are relative, not absolute. A gap of a few points at the top is smaller than the method's uncertainty, so read the top five as a group, not a strict order.
  • Mostly at maximum effort: each model counts with its best setting on each board, usually max/xhigh reasoning. Faster or cheaper settings of the same model can be much weaker.
  • Prices are per token, not per task (USD per 1M tokens, input/output, standard list price). Models that think a lot use more tokens and cost more in practice than the table shows. Value = overall score ÷ blended price (3 : 1 input : output).
  • Confidence = number of independent sources (high ≥ 6, medium 3–5, low ≤ 2). A model is ranked only with at least 3 sources and category coverage of at least 45 %.

            MetodaMethod

            Kako je indeks izračunanHow the index is computed

            1. Pregled virov po šestih merilih (zgoraj). Zavrnjeni so zbiralniki, ki le prepisujejo številke prodajalcev ali drugih lestvic brez lastnih meritev, SEO strani ter zastarele ali ustavljene lestvice.
            2. Zajem: številke so vzete iz strojno berljivih podatkov vsakega vira (vgrajen JSON, CSV/JSON datoteke, GitHub, Hugging Face), ne iz izrisanega besedila. Česar ni bilo mogoče prebrati, ni ocenjeno.
            3. Poenotenje imen modelov (predpone ponudnikov, datumske in nastavitvene pripone, vzdevki). Nastavitev (napor, ogrodje) je shranjena pri vsakem rezultatu.
            4. Najboljša nastavitev na lestvico: če je model na isti lestvici večkrat, šteje njegov najboljši rezultat.
            5. Percentil: na vsaki lestvici dobi vsak model rang 0–100 med modeli v indeksu. Lestvice z manj kot 3 takimi modeli se ne upoštevajo.
            6. Utež lestvice = ugled/5 × pomen × svežina ÷ število lestvic istega vira v isti kategoriji. Svežina: ≤ 180 dni 1,0; ≤ 365 dni 0,5; starejše 0,25.
            7. Popravek za moč polja (dvosmerni fiksni učinki): za vsako kategorijo se oceni pct ≈ θ_model + β_lestvica; θ je ocena kategorije. Brez tega bi stari modeli na zastarelih lestvicah prehiteli svoje naslednike.
            8. Skupna ocena = tehtano povprečje razpoložljivih kategorij (uteži spodaj). Hitrost, cena in »drugo« se prikazujejo, a ne vstopajo v oceno kakovosti.
            9. Slovenščina: isti izračun samo na slovenskih lestvicah (EuroEval Slovene, SloBench, Slovenska pogovorna arena).
            10. Cena: uradni cenik ponudnika, sicer Artificial Analysis, sicer OpenRouter. Mešana cena = (3 × vhod + izhod) / 4.
            1. Source vetting on six criteria (above). Rejected: aggregators that only copy vendor-reported or third-party numbers without their own runs, SEO farms, and stale or paused boards.
            2. Extraction: numbers come from each source's machine-readable data (embedded JSON, CSV/JSON files, GitHub, Hugging Face), not rendered text. What could not be read is not estimated.
            3. Name canonicalisation (vendor prefixes, date and setting suffixes, aliases). The setting (effort, harness) is kept with every result.
            4. Best setting per board: if a model appears several times on one board, its best score counts.
            5. Percentile: on each board every model gets a rank 0–100 among the models in the index. Boards with fewer than 3 such models are ignored.
            6. Board weight = respectability/5 × relevance × freshness ÷ number of boards of the same source in the same category. Freshness: ≤ 180 days 1.0; ≤ 365 days 0.5; older 0.25.
            7. Field-strength correction (two-way fixed effects): for each category pct ≈ θ_model + β_board is fitted; θ is the category score. Without it, old models on stale boards would outrank their successors.
            8. Overall score = weighted mean of the available categories (weights below). Speed, price and "other" are shown but never enter the quality score.
            9. Slovenian: the same fit on Slovenian boards only (EuroEval Slovene, SloBench, Slovenian Chat Arena).
            10. Price: official vendor list price, else Artificial Analysis, else OpenRouter. Blended price = (3 × input + output) / 4.

            OmejitveLimits

            • Percentil zavrže velikost razlik: prednost 0,2 točke in 10 točk štejeta enako.
            • »Najboljša nastavitev« daje prednost modelom, ki so bili merjeni pri največjem naporu; cene na žeton podcenijo modele, ki porabijo veliko žetonov.
            • Lestvice, povezane s ponudniki podatkov (Scale SEAL, Snorkel), imajo nižji ugled; nekatere lestvice mešajo agentna ogrodja.
            • Pokritost je neenakomerna: najnovejših modelov ni na počasi posodobljenih lestvicah. Stolpec zaupanja to označi.
            • Slovenskih dokazov je malo; SloBench rezultati so večinoma starejši modeli, slovenska arena ima malo glasov.
            • Poenotenje imen je hevristično; v dvomu glej models[].board_scores v JSON.
            • Percentiles discard the size of gaps: a 0.2-point lead and a 10-point lead count the same.
            • "Best setting" favours models measured at maximum effort; per-token prices understate models that use many tokens.
            • Boards tied to data vendors (Scale SEAL, Snorkel) carry lower respectability; some boards mix agent harnesses.
            • Coverage is uneven: the newest models are missing from slow-updating boards. The confidence column flags this.
            • Slovenian evidence is thin; SloBench results are mostly older models and the Slovenian arena has few votes.
            • Name canonicalisation is heuristic; when in doubt see models[].board_scores in the JSON.
