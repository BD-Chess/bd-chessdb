For a complete project

A private bundle preserves binary files and folder paths. Restore it in Read, download the ZIP and extract it. It is an archive, not a server or a sandboxed application runner.

What stays local?

The authoring app makes no network requests. No AI proxy, DNS lookup, analytics or external font is used. Only display preferences are stored. Files, keys and your reading library stay in tab memory. A browser password manager may separately offer to save a key.

What is the encryption?

New exports use a versioned v4 envelope: AES-256-GCM, PBKDF2-HMAC-SHA256 (600,000 iterations by default), random salts and IVs, a random content key and separate password-wrapped key slots. Header fields are authenticated. Built-in restoration checks run before download.

This is standard cryptography, not a new cipher, certification or proof of security. Offline password guessing remains possible; choose a long unique passphrase. A public domain name does not add secret entropy.

What is not protected?

An authorized reader can copy the decrypted content and code. Downloaded copies cannot be revoked by deleting the hosted file. External assets are not automatically bundled or encrypted by whole-page mode. Secrets needed by browser code are visible after unlocking; server credentials belong on a server.

Compatibility & constraints

Use a current browser with Web Crypto. HTTPS or localhost is recommended; local-file support depends on the browser. Page and section inputs must be UTF-8. Section mode requires well-formed supported containers and does not auto-edit Content Security Policy. Hosting headers, external resources, app initialization and original scripts need an integration test.

Read supports new v4 files, old Smart whole-page HTML, legacy .8zv version 3, original 500K section files and BD HTML Protector v3 whole pages with the original domain. Legacy section restoration is normalized, not byte-exact. Other historical profiles are not guessed.

Copy identifiers & privacy

Copy marking is optional. It adds a random removable identifier, without rewriting words or adding tracking URLs. Keep the separate recipient manifest private. The tool does not identify people or promise leak attribution.

Origins & release status

Based on BD’s 8Z Shield Smart, the original section engine and BD HTML Protector v3. The original files remain unchanged. This is a release candidate: verify it on your real target devices and publishing environment before commercial launch.
