AI8 Model Resource Control

The model/provider/resource truth layer: orthogonal availability facts, local budgets, auditable routing and call receipts.

CANDIDATENo global route winner

Resource truth is multidimensional

Entitlement, product surface, account catalog visibility, callability, usage allowance, rate-limit state, reset windows, provider health, API availability and local AI8 budget are independent facts. Unknown values remain unknown.

Forbidden inference: a quota/reset change is not evidence that a desired model became entitled, visible or callable.

One durable substrate; route profiles, not grand architectures

Work profile

Human-rich console/tool path when it fits the task and available resource state.

API profile

Auditable specialist/delegated calls when API capability, permission and local budget justify them.

Mixed profile

Combination only when matched workload evidence earns the added complexity.

No route is globally promoted. The router must be inspectable and can route downward when a stronger model adds no value.

Reset incident: recorded, not yet learned

The initiating resource mistake produced a lesson candidate and regression target, but R3H2.1 explicitly refuses to call it learned until a shared causal-use experiment shows a permission-matched decision change on a novel surface while placebo/stored-only controls do not create false credit.

Scarce reset consumption remains human-governed; the first prototype does not automate it.

Sudoku slice

Use the cheapest already-available route profile that satisfies the frozen slice contract. Cross-provider routing, automatic resets and advanced bandits stay dormant unless a real workload requires them.
