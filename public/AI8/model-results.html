Oddani SLAIF teki po modelih (21.–26. 10.)Submitted SLAIF runs per model (21–26 Oct)

Zgornji stolpci ostajajo starejši zgodovinski povzetek. Spodaj so preverjeni javni povzetki oddanih tekov: en tek je en model na eni nalogi. PASS določa izvirni zamrznjeni evaluator; PARTIAL zajema tehnične vrzeli, nepopolne odgovore, pisne zasnove (DESIGN_ONLY) in raziskovalne pilote politike z determinističnim reševalnikom. HTTP 200 je samo prenos. Dostopnost velja za posamezen datirani tek, ne za današnji dostop. Strogi nizi, ocene zasnov in piloti niso združeni v eno oceno; to ni lestvica modelov.

The bars above remain the earlier historical summary. Below are validated public summaries of submitted runs: one run is one model on one task. PASS is set by the original frozen evaluator; PARTIAL covers technical gaps, incomplete answers, written designs (DESIGN_ONLY) and research policy pilots with a deterministic solver. HTTP 200 is transport only. Availability applies to each dated run, not to access today. Strict suites, design scores and pilots are not merged into one score; this is not a model ranking.

Kaj pomeni PASS in kaj manjka?What does PASS mean, and what is still missing?

HOME kakovostni PASS zahteva pravilen format, shemo in vsebino. HTTP 200 pomeni samo uspešen prenos. Osnovni testi so tekli po protokolu cold_per_test; neprekinjena serija na naloženem modelu ni dokazana. Cloud MAL nima potrjenega enotnega T001–T010 teka. SLAIF izidi pokrivajo različne naloge in zgodovinski dostop.

HOME quality PASS requires valid format, schema and content. HTTP 200 only confirms transport. The basic tests used cold_per_test; a continuously loaded series is unproven. Cloud MAL has no verified uniform T001–T010 run. SLAIF outcomes cover different tasks and historical access.
