KAJ TI POVE TEST

Odgovor z naslednjim korakom.

Rezultat velja za model in nastavitve ob testu. Konzole lahko zahtevajo prijavo in izbiro prave ekipe ali projekta.

API deluje

Prejet je pravilen, enkratni kontrolni niz. Pokažemo vrnjeni ID modela, trajanje in porabo tokenov, če ju API sporoči.

Preveri nastavitev ali kvoto

401, 403, 404 in 429 imajo različne vzroke. Pri vsaki napaki dobiš razlago in povezave do API ključev, porabe ter pomoči.

Neznano ni enako neveljavno

CORS, timeout ali ustavitev ne potrdijo stanja ključa. Zahteva je morda že dosegla ponudnika. Pred ponovitvijo preveri porabo.
