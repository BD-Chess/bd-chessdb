One committed operational world

8Z Control is the authoritative committed project/arena/run/evidence/decision world. Other components propose, execute, observe or evaluate through typed references rather than creating parallel canonical truth.

Transactional publication

Publication is hash-bound, fenced against stale writers, validated, auditable and rollback-capable.

Architecture page ≠ operational cockpit

This page describes the R3H2.1 candidate contract. The existing 8Z Control / Workbench is a separate public-safe operational view with its own live refresh and dashboard behavior. This build does not modify that operational state machinery.

Public projection rule

committed Control state + upstream evidence ↓ validated KnowledgeRelease allowlist ↓ static public projection

No private path, credential, protected strategy or security-sensitive control detail is made public merely because it exists in operator state.
