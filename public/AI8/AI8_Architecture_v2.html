Executive Summary

AI8 (AI ∞ — Continuous Intelligence Architecture) is a persistent, self-monitoring, self-selecting control and discovery architecture built on the Minimum Description Length × Dynamic Complexity Control (MDL × DCC) kernel. Unlike stateless, single-burst inference systems (prompt → response → silence), AI8 operates as a continuous process governed by a five-layer control hierarchy (G1–G5), three levels of recursive self-selection (R1–R3), and an autonomous seed-generation loop (R).

This v2.2 specification incorporates mathematical, epistemic, and multi-agent verification refinements over v1 and v2.1:

1. Strict separation between ontological layers (O1 Physical/Computational Substrate vs. O2 Non-Computational Consciousness Field) and five substrate control layers (G1–G5), eliminating category errors between control actuators and phenomenological field coupling.

2. Exact boundary-vanishing, strictly concave formulation of dynamic openness (Ψ(h)) via the exponential binary Kullback–Leibler / Beta kernel, paired with explicit distinction between causal coupling/integration (k, Cₙ) and computable multi-worker operational proxies (k̂, Ĉₙ), plus strict separation from control actuation (u).

3. Stabilized self-calibrating band regulation with hard informational guardrails (h_floor, h_ceil), hysteresis deadbands, timescale separation (τ_R3 ≫ τ_R2 ≫ τ_R1 ≫ W), and an exogenous objective anchor on G4 to prevent wireheading.

4. Bit-consistent MDL accounting, blinded multi-agent review independence rules in R, and strict separation between empirically measured domains (8zTSP, 8zC-M) and candidate target domains under active research.

1. Canonical Glossary & Layer Separation

To prevent cross-domain collision between ontology, control theory, and software engineering, AI8 v2.2 enforces distinct notation:

  • O1 (Ontology — Computational & Physical Substrate): Silicon, neural tissue, and discrete state transitions. Algorithmic, deterministic or stochastic, directly measurable.
  • O2 (Ontology — Consciousness Field CF): Postulated in the AC / CFH / CCH companion papers; non-computational phenomenal ground.
  • G1–G5 (Control on O1): Five engineering governance layers operating strictly inside O1 (replacing overloaded "Layer 1–5" labels).
  • R1–R3 (Recursion on O1): Three control recursion levels (base search → governor selection → meta-governor selection).
  • R (Discovery on O1): Autonomous Seed & Lens Generation Layer (ssMDL×DCC-R), feeding candidate hypotheses into G1–G5.
  • k ∈ [0, 1] (Regime Metric — Effective Structural Coupling): Causal bidirectional interaction bandwidth between active subsystems (approximated in software fleets by proxy k̂ plus interventional ablation).
  • Cₙ ∈ [0, 1] (Regime Metric — Integration / Coherence): Synchronized dynamical integration across active threads/workers (approximated in software fleets by proxy Ĉₙ).
  • h ∈ [0, 1] (Sensor Signal — Normalized Complexity): Normalized sequential complexity, e.g., LZ76_norm of an operational symbol stream over window W.
  • Ψ(h) ∈ [0, 1] (Regime Metric — Dynamic Openness): Strictly concave function of h on [0, 1] peaking at Ψ(h*) = 1 for any target h* ∈ (0, 1) and vanishing exactly at both boundaries (Ψ(0) = 0, Ψ(1) = 0).
  • S ∈ [0, 1] (Regime Metric — Dynamical Regime Index): S = k · Cₙ · Ψ(h). Tracks whether an O1 process occupies the productive, integrated, and differentiated dynamical band.
  • u ∈ [0, 1] (Actuator — Control Input Variable): Adjusted in real time by DCC to steer O1 search and attention knobs (never identical to Ψ(h)).

2. Core Control Loop: Digital Complexity Controller (DCC)

2.1 The Two Failure Modes

Every uncontrolled search, inference, or coordination process degenerates into one of two failure modes:

  • Seizure (h → 0): Premature convergence on a single attractor, repetitive loop, or retrieval lock. High regularity, zero novelty.
  • Noise (h → 1): Unstructured random thrashing, high token/compute burn, zero cumulative structure.

The Digital Complexity Controller (DCC) regulates the process in real time to maintain h inside a productive target band [h_low, h_high] centered on h* ∈ (0, 1) between seizure and noise.

2.2 Exact Concave Ψ(h), Operational Proxies k̂ and Ĉₙ, and Actuator u

1. Exact Concave Dynamic Openness (Ψ(h) ∈ [0, 1]):

(Correction over v2.1: an unclipped Gaussian is strictly positive at h = 0, 1 and loses concavity in the tails, whereas 4h(1 - h) peaks only at h* = 1/2.)

For any target complexity h* ∈ (0, 1) (including narrow empirical regimes such as h* ≈ 0.05 in TSP local search), AI8 v2.2 defines Ψ(h) on h ∈ (0, 1) via the normalized Beta / exponential binary Kullback–Leibler kernel:

Ψ(h) = (h / h*)^α · ((1 - h) / (1 - h*))^β = exp( -γ · D_KL(Bern(h*) || Bern(h)) )

with α = γ · h*, β = γ · (1 - h*), and 0 < γ ≤ 1 / max(h*, 1 - h*), extended by continuity to Ψ(0) = 0 and Ψ(1) = 0.

Canonical parameter-free form (γ = 1): α = h* and β = 1 - h* (α + β = 1).

Symmetric quadratic special case (h* = 1/2, γ = 2): α = 1, β = 1, recovering Ψ(h) = 4 · h · (1 - h).

Verified mathematical properties: Because 0 < α ≤ 1 and 0 < β ≤ 1 (with α · β > 0 and not both equal to 1 except 4h(1 - h) where Ψ''(h) = -8 < 0), the second derivative

Ψ''(h) = Ψ(h) · [ α(α - 1)/h² - 2αβ/(h(1 - h)) + β(β - 1)/(1 - h)² ]

is strictly negative for all h ∈ (0, 1). Thus Ψ(h) is strictly concave across the entire interval [0, 1], achieves its unique global maximum Ψ(h*) = 1 at arbitrary h* ∈ (0, 1), and satisfies exact boundary collapse Ψ(0) = 0 and Ψ(1) = 0. Consequently, S = k · Cₙ · Ψ(h) vanishes in both pathological limits.

2. Structural Coupling (k) vs. Operational Proxy (k̂) ([HYPOTHESIS / PROXY]):

In multi-worker software arenas (M parallel workers over epoch N), raw message/state exchange rate

k̂ = min(1, E_exchanged / E_capacity)

serves as a cheap observable proxy, not proof of effective causal coupling (high message volume can still be ignored by recipients). Establishing effective coupling k requires pairing k̂ with causal sensitivity checks (e.g., non-zero transfer entropy or measurable trajectory divergence relative to an isolated k = 0 ablation control).

3. Integration (Cₙ) vs. Operational Proxy (Ĉₙ) ([HYPOTHESIS / PROXY]):

4. Oscillator / EEG systems: Phase-Locking Value (PLV) across channels.

1. Multi-worker discrete fleets (M ≥ 2): Mean pairwise structural agreement across active worker states X₁, ..., X_M (e.g., edge Jaccard overlap on tours or normalized mutual information across generator choices):

Ĉₙ = (2 / (M · (M - 1))) · Σ_{i<j} Sim(X_i, X_j)

Ĉₙ is an operational proxy: static overlap from identical initialization must be discounted (e.g., relative to baseline seed overlap), and high Ĉₙ alone never suffices because clone collapse (Ĉₙ → 1) drives innovation h → 0 and collapses Ψ(h) → 0.

5. Actuator vs. State (u vs. Ψ(h)):

Control parameters such as perturbation strength, candidate neighborhood radius, temperature, or memory-trust weight u_memory ∈ [0, 1] (used in Flip4M v4) are actuators (u) on O1 that steer the system's operating point; they are never equated with Ψ(h).

2.3 Stabilized Self-Calibrating Band Regulation

AI8 v2.2 explicitly declares its fixed architectural hyperparameters (W buffer length, N update cadence, step size Δu, deadband δ, and guardrails h_floor, h_ceil):

6. Protection Against Anchor Collapse: Self-calibrating [h_low, h_high] from observed history H enforces hard informational bounds so a cold start inside seizure or noise cannot lock the band inside pathology:

h_low = max(h_floor, P_25(H)), h_high = min(h_ceil, P_75(H)), with h_high - h_low ≥ Δ_min > 0 and h* = (h_low + h_high) / 2.

7. Hysteresis Deadband Against Limit-Cycle Chattering:u updates only when h < h_low - δ or h > h_high + δ, preventing oscillation across window boundaries due to buffer lag W.

8. Level-Specific Polarity Rules (Resolving Semantic Inversion): The same sensor reading h requires opposite control polarity depending on whether DCC is governing an inner search generator (G1) or evaluating regime persistence (G2):

  • G1 (Search Execution — symbol stream I: step outcomes 1 = improvement, 0 = reject):
  • Low h (h < h_low - δ): Seizure / Local Optimum → Decrease u (broaden search, increase perturbation).
  • High h (h > h_high + δ): Random Thrashing → Increase u (tighten acceptance, focus exploitation).
  • G2 (Domain / Regime Routing — symbol stream I: winning model/generator ID per epoch):
  • Low h (h < h_low - δ): Persistent Regime → Maintain trust / allocation in active specialist until residual degrades.
  • High h (h > h_high + δ): Regime Breakdown / Chaos → Reduce exposure / trigger fallback exploration.

3. Bit-Consistent MDL Selection & Recursive Closure (R1–R3)

3.1 Uniform Bit Accounting

Every candidate model, heuristic, or DCC configuration M is evaluated by Minimum Description Length (MDL) in uniform bit units:

L_total(M | D, B) = L_model(M) + L_residual(D | M, B)

where:

  • L_model(M) encodes the exact selector index (log₂(|Universe|) bits), sensor/law parameters, and framing overhead — never 0.00 bits for multi-parameter controllers such as ADSR or PID (tables zero-anchored to the best variant are explicitly labeled ΔL_total).
  • L_residual(D | M, B) encodes residual error or optimality gap under declared compute budget B using a fixed, pre-declared coding distribution (eliminating arbitrary human weights such as gap% × scaling_constant).

3.2 Three Levels of Control Recursion (R1–R3)

AI8 separates control recursion (R1–R3) from methodological self-similarity (applying multi-scale decomposition MSTD to both spatial coordinates and cognitive idea-threads):

  • R1 (Base Loop): MDL selects the best domain model/solver; DCC regulates its search dynamics (u).
  • R2 (Governor Selection): MDL evaluates competing DCC configurations (Sensor, Control Law, Representation) conditioned on budget B; Meta-DCC regulates the meta-arena budget.
  • R3 (Meta-Governor Closure): MDL selects the Meta-DCC policy itself. Recursion terminates naturally when adding a meta-level costs more description bits (L_model) than it saves in residual cost (L_residual).

3.3 Preventing Deadlocks & Wireheading

1. Timescale Separation: Adaptation timescales must satisfy τ_R3 ≫ τ_R2 ≫ τ_R1 ≫ W so budget-sensitive specialists (e.g., tunneling at short budgets vs. interference at long budgets) are evaluated over full dwell horizons without chattering.

2. Fibrillation Fallback (G4): Non-smooth control laws (such as ADSR, which exhibits sharp bifurcation between exact convergence and sudden collapse) run under a G4 stability monitor that triggers deterministic fallback to a smooth baseline (BB or EMA) upon variance spikes.

3. Exogenous Objective Anchor on G4: Internal MDL cannot rewrite its own ground-truth loss function, preventing wireheading. Ground-truth evaluation metrics (exact tour length, SHA3-256 bit-exact reconstruction, hard compute/wall budgets, and human-defined mission goals) remain strictly exogenous to G4.
