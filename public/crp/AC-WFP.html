Research orientation

What this paper claims—and what it does not

Methodological prior

MDL is used as an auditable model-selection sensor. Its cross-domain usefulness motivates the test; compression alone does not establish an ontology.

Neutral scientific baseline

All executable claims are stated first for Ω. A successful closure-discovery mechanism would not by itself establish Absolute Consciousness.

Three separate challengers

MPRC2 searches a richer split–merge–overlap–change-point grammar. MSR2 makes the spectral operator, state weighting, flow scale and recovery channel causally operative in proposal generation. LEC uses a bounded latent-energy recognition/generative architecture only to propose candidates; an independent held-out temporal MDL scorer remains the judge.

Strong alternatives, not straw controls

Every proposed whole-first mechanism must compete not only against whole, singleton and random covers, but also against spectral clustering, dynamic stochastic-block, hidden-regime, change-point, low-rank and predictive-state baselines. The legacy A2 label PREDICTIVE_STATE is interpreted honestly as PREDICTIVE_STATE_HEURISTIC; a genuine predictive-equivalence challenger is separately specified as CAUSAL_STATE_MACRO.

Effective-Part Certificate

No single compression score is allowed to promote a candidate part. The candidate must accumulate a typed certificate covering restriction, prediction, local-to-global compatibility, recovery, intervention, scale, naturality/null specificity and full model cost. Axes not implemented in the current A2 executable remain explicitly UNEARNED, not silently passed.

Open scientific gates

Generic stable parts, intervention-robust closure, a finite causal cone, 3+1 dimensions, realistic matter and any AC-specific physical effect remain unearned.

\[ \boxed{ \operatorname{EPC}(C) = (R,P,G,Q,I,S,N,L), } \]

0.2 Algorithmic information, MDL and MML foundation

where 𝒞M denotes the executable codebook and modelling machinery. The exact implementation may differ, but it must be finite, reproducible and fixed before the confirmation split is opened.

Scope: MDL is a sensor for generalizing structure. It is not a metaphysical proof that reality “is compression,” and a short model can still be wrong outside its declared data and intervention domain.

1. The core proposition

The parts-first picture assumes local constituents and attempts to build the universe from them. AC–WFP tests the inverse explanatory order:

Locality, particles, fields and spacetime may be stable effective structures generated within a globally constrained Whole.

This is not the claim that large spatial objects create smaller spatial objects. If spacetime is emergent, the Whole is not larger in metres. It is more inclusive and ontologically prior to any particular factorization into local pieces.

The strongest neutral statement is:

A physical world is a stable relational regime in which compatible restrictions of Ω acquire predictive closure, recoverable records, causal reach, geometry, energy–momentum and persistent modes.

The AC interpretation adds:

Ultimate actuality is not wholly devoid of presence. Physical organization localizes, stabilizes and enriches bounded relative consciousness rather than creating phenomenal presence from absolute non-presence.

For a finite relational history

The mechanism receives only the visible finite relational system and the declared training times. It may use internal train/validation splits within training history, but it cannot inspect held-out score times, generator identity, target cover, target regimes, effect target or oracle score.

A mechanism returns one serialized candidate and a complete proposal trace. The held-out scorer fits no new proposal parameters. A recovery map is estimated from the permitted fit history and evaluated on later held-out time.

For every unordered node pair (i,j) at time t, the context contains:

A frozen Dirichlet-multinomial prequential code supplies

\[ L_{\rm temporal}(X_{\rm score}\mid X_{\rm fit},C). \]

Because the code is sequential, reversing time can change the score. Because category priors are symmetric, a global permutation of relation labels must leave the total score invariant when the candidate is transported consistently.

\[ \boxed{ \|[\sigma_s^\omega(A_i),B_j]\| \le C\|A_i\|\|B_j\| \exp[-\mu(d(i,j)-v|s|)]. } \]

MCCC is not implied by modular theory and is not a primitive law. It is a downstream order parameter for a quasi-local phase.
