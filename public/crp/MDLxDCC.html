How to read this page: it is not one absolute ranking. The map is split into three layers. ASI appears as a destination, not as a normal market candidate. Verified anchors are the domains that already carry proof weight. Candidate domains are listed once and can be re-sorted by lens: commercial, upstream research value, MVP speed, and other structural views. Each entry now has a stable code: D1 for the destination, V1–V6 for verified anchors, and C01–C53 for the candidate field. Average LLM scores are shown only as a compact secondary signal; clicking an AVG badge reveals the per-model breakdown. AVG now uses only Claude + DeepSeek + Gemini + ChatGPT.
Why this page uses $3T+/year: this expanded 60-domain map now uses a directional project-level upside estimate of $3T+/year. The shift is not based on any imaginary prior public version of this page. It reflects the addition of several very large omitted surfaces that materially change the map: gaming and real-time 3D worlds, immersive video creation, telecom routing and orchestration, HPC / supercomputer governance, digital twins, aerodynamics / CFD, broader robotics, weather ensemble governance, and hybrid quantum workflows. It is still an upside estimate for the overall project field, not a fake-precise TAM claim.
