1. Boundary#

Boundary: This is not an official ARC Prize submission, does not expose proprietary MDLxDCC core, and does not claim that ARC is solved. The measured signal is train-fit, LOO survival, category/family routing value, primitive discovery, and failure interpretability.

The arena intentionally uses dynamic primitives learned from train pairs. It should not memorize ARC task IDs, hardcode task-specific solutions, or bake in ARC answer tables. The value is in discovering which primitive families explain which task families under MDL/DCC pressure.

2. Method#

The v0.4 pipeline is:

ARC JSON → grid validation → features/categories → candidate primitive families → MDL score → DCC trace → train-fit + LOO → test prediction → JSON/HTML reports

v0.4 added --cat slicing, --workers, budget presets, family category filters, and prior-result reruns. The run summary script flattens each run into summary_index.csv and summary_index.json with exact, HIGH, LOO average, candidate count, runtime, chain2 exact count, family signals, and failure buckets.

Good structure: JSON is already the source of truth. HTML and CSV are views over run artifacts. This matches the TSP/NAS/Sudoku/CW arena pattern: arena remembers, compares, and then routes.

7. Natural-law primitive lens#

  • substitution_expand — morphogenesis: one cell expresses a learned motif.
  • wire_connect / line_connect — signal wires and priority/crossing behavior.
  • sequence_extend — growth vector / phase extension.
  • macro_grid / scale_up_integer / block_expand — tissue/lattice reasoning.
  • ray_cast / marker propagation — instruction from marker to boundary.
  • gravity_pack / motion/object alignment — physical relaxation, packing, and contact.

The current data supports the lens: natural-law primitives are not decorative. They produced exact wins in v0.3b and continue to appear in exact and near-miss families in v0.4.

8. Arena philosophy#

The arena should remain wide. A low global exact rate is not the only score. The more important diagnostic is whether the arena finds dynamic primitive families, separates task families, exposes wasted compute, and makes failures more interpretable.

Seed → bridge → test → result. Do not kill a path because the first global slice is weak. Route it, compare it, and let MDL/DCC decide under category evidence.

10. Roadmap#

v0.5 priorities

  • Category confidence: store category reasons and evidence scores; support --cat-report, prev_exact, prev_failed, slow_risk, near_miss_small_rule_gap, and composed filters.
  • Memory layer: add arc_az.json and task cache with task signature hash, category evidence, successful/failed/near-miss families, runtime cost, and best candidate summaries.
  • DCC budget governor: make chain2 routed, not global; add per-category family activation and per-family caps.
  • Primitive expansion: macro-grid cell rules, periodic lattice completion, symmetry completion, marker rays, enclosed-region recolor, object matching, counting, crop-between-markers, object gravity/contact, local cellular rules, and blockwise majority/rank maps.
  • Failure mining: split the broad buckets into actionable buckets such as object matching, counting, macro-grid, symmetry, marker instruction, local cellular, canvas resize, and exact-fit-but-low-LOO.
  • Report viewer: show input/target/prediction/diff, test prediction, winner/top five, categories/reasons, failure bucket, residual heatmap, and filters by family/category/confidence.
Next overnight stance: ready to keep running v0.4 to completion, but v0.5 should not simply add more beam. The next build should add memory + routed budget + sharper failure buckets + a wider dynamic primitive pack.
