1. Clear verdict

Potential remains. Do not narrow the arena too early.

The first master run does not prove that ordinary finished ZIP, 7Z, PNG, FLAC, JPG, or MP3 files can already be compressed 5–15% further. But it also does not kill the branch. The right conclusion is stricter and more useful: the scout should keep searching broadly across final bytes, selected weak final files, codec-internal streams, raw/procedural positives, and 8Z-internal residual layers — while reporting each layer separately.

BD correction accepted: do not shrink the search space just because the earliest clean signal appears before the final entropy layer. Let the arena search everything, even if the longer runs take time. Evidence may still appear in rare final-byte cases, weak encoders, bad settings, metadata/tile/block artifacts, dictionaries, or specific procedural payloads.

3. Wide-arena policy

Do not kill paths early. Search all; classify hard.

The arena should remain broad even if it runs for days. The narrowing happens only in the public interpretation, not in the search space.

Keep alive
  • ordinary final compressed files
  • selected weak/structured final files
  • codec-internal streams
  • raw and identity-final controls
  • 8Z residual/token layers
  • formula, CA, PRNG, LFSR/GF, geometry, later PySR candidates
Classify separately
  • TRUE_FINAL_WIN: actual post-codec final-stream MDL win
  • CODEC_INTERNAL_WIN: structure before/inside codec entropy layer
  • RAW_SYNTHETIC_RECOVERY: positive-control result
  • IDENTITY_FINAL_RECOVERY: as-is duplicate / not a true codec win
  • WEAK_HINT: interesting but not promotion-grade
  • NULL_CLEAN: useful negative/control outcome
Rule: wide search is allowed; wide claims are not. A long run may search everything, but the report must not mix synthetic raw recovery with true final compressed-file compression.

5. Core model

Generator + residual + fair cost accounting.

X = source bytes or selected representation layer
B = target layer bytes  // raw, true-codec-final, codec-internal, 8Z residual, ...
G = deterministic generator(theta, len(B))
R = residual_transform(B, G)

Accept iff:
L(generator_family + theta + transform + residual_codec(R)
  + metadata + search_budget_cost + phi_cost)
< L_fair_baseline(B) - safety_margin

And:
exact_reconstruction(B) == true
controls_clean == true
same_budget_null_beaten == true
6. Evaluation gates

Broad search needs harder gates, not smaller imagination.

Reject / demote
  • tiny chunk lucky wins
  • wrong-family micro-hits
  • identity-final hits counted as final-codec wins
  • wins that vanish under same-budget nulls
  • wins that lose to stronger baseline recompression
Promote
  • strict MDL win including overhead
  • fair baseline beaten
  • generator ablation beaten
  • empirical null beaten
  • exact reconstruction verified
  • repeatable across seeds/chunks/files where claimed

10. Failure modes

The scout must not become a coincidence miner.

Premature narrowing

Seeing early signal in one layer does not justify killing the other layers before long runs and real corpora.

False positives

Huge generator/rule/transform searches can find lucky local wins if search cost is undercharged.

Layer confusion

Identity/as-is synthetic bytes must not be reported as true final compressed-byte evidence.

Weak baseline trap

If a stronger classical codec alone wins, do not credit math.

Tiny chunk overfit

Small chunks can create fake victories. Report them as debug until replicated.
