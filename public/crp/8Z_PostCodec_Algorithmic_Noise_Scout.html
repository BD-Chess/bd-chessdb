8Z Post-Codec Algorithmic Noise Scout

A falsification-first arena for testing whether deterministic algorithmic-noise generators can reduce residual cost on selected codec and 8Z representation layers.

The useful claim is narrow: not “all compressed files get smaller,” but “some structured residual layers may still contain recoverable algorithmic signal.”

Python arena v0.1.1 complete Selftest + smoke + standard + deep done 115,600-candidate deep panel Strict MDL + exact verify No real post-codec claim yet

Strong version

Search for deterministic generator + residual descriptions that beat strong baselines under MDL, ablation, same-budget nulls, and exact reconstruction.

The first complete arena result is exactly what a scout should show: known synthetic CA/PRNG structure is recoverable, controls stay clean, and compressed synthetic variants do not get promoted by accident.

Weak version rejected

Do not claim arbitrary ZIP, 7Z, PNG, FLAC, JPG, or MP3 final bytes can already be compressed another 5–15%; this run did not test ordinary real final containers.

Final bytes are still the stress test, not the main expected win layer. v0.1.1 found no ordinary compressed-file proof. The first final-byte positives are synthetic known-generator recoveries, not ordinary ZIP/PNG/FLAC/JPEG/MP3 evidence.

3. Core model

Generator + residual, not magic compression.

Description
X = original file
B = codec_or_representation_layer(X)
G = deterministic_noise_generator(theta, len(B))
R = residual_transform(B, G)

Accept iff:
L(generator_family + theta + transform + residual_codec(R)
  + overhead + phi_cost + search_budget_cost)
beats fair baselines and controls.
Generator families
  • Constants and no-op ablations.
  • Small PRNGs and seed sweeps.
  • Cellular automata: rules 30, 90, 110, 184.
  • Later: LFSR/GF, symbolic formulas, learned formula synthesis.

5. Acceptance gates

v0.6+ rule: MDL win is necessary, not sufficient.

Rejected gate

Strict MDL win OR survives same-budget controls

This is too weak. It lets lucky search survive.

Current gate

Strict MDL win AND fair baseline AND ablation AND null AND exact verify

This is the minimum gate before any hit becomes a promoted structured positive.

Show the full gate checklist
  • Beat min(len(B), strong_codec(B), strong_codec(layer)), not just the source container size.
  • Include generator descriptor cost, transform descriptor cost, residual-codec cost, phi_cost, and search-budget cost.
  • Beat no-op and generator-ablation baselines.
  • Beat same-budget empirical nulls with locked seeds and comparable search volume.
  • Verify exact reconstruction by SHA3 or equivalent byte-exact hash.
  • Repeat across seeds / chunks before upgrading from debug hit to promoted hit.

9. Failure modes

The scout must not become a coincidence miner.

False positives

Huge offset/rule/transform searches can find lucky local wins. Charge search cost and compare same-budget nulls.

Weak baseline trap

If a stronger codec alone wins, do not credit math.

Tiny chunk overfit

Small chunks can create fake victories. Keep them as debug unless repeated and costed.

Magic-generator drift

π, CA, PRNG, geometry, and formulas are fuel, not proof. Arena decides.

Final-byte accounting

Do not count as_is raw-equivalent final layers as true post-codec wins. Report true_final_compressed_positive separately.

10. Next action

Patch v0.2 before bigger runs.

Next concrete move: build Noise Scout v0.2 with stricter layer semantics and stricter promotion gates, then rerun standard/deep. Do not scale to real ZIP/PNG/FLAC/JPG/MP3-style files until the verdict language cannot overstate what happened.
v0.2 patch list

  • Only trigger a public final-byte verdict when the layer is actually compressed/entropy-coded.
  • Demote wrong-family micro-hits unless they exceed a stronger savings threshold and survive family-consistency controls.
  • Report unique target wins separately from duplicate transform/chunk hits.
