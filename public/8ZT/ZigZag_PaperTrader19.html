📖 Help & Documentation — v2.0

🎯 What Is This?

A mean-reversion paper trading simulator that connects to live crypto exchanges via WebSocket. It detects ZigZag swing patterns, enters counter-trades when price overextends, and averages down if price continues against the position. The math guarantees that every trade is closed at a profit (100% gross win rate).

v2.0 NEW: Legs Sync (MTF direction consensus), Escape mechanism, Volume-weighted extension, DCC regime stability, Macro bias EMA, Sqrt compounding.

★ Legs Sync — Multi-Timeframe Direction Consensus

The biggest single feature — proven +67-78% PnL improvement on BTC. At every bar, the engine checks what direction the ZigZag is pointing on multiple higher timeframes. If they all agree with the trading TF's direction, position size is boosted up to Max Mult (default 3×). If they disagree, trade at 1× base.

How it works: When ON, the engine fetches 1-minute data from Binance and resamples it internally to both the trading TF and each monitor TF. This guarantees data consistency — all TFs are derived from the same 1m source. The ZigZag detector runs independently on each TF, building a per-bar direction array (+1=going up, -1=going down). At trade entry, the consensus score determines the size multiplier.

Fibonacci TF ladder auto-selects monitor TFs above the trading TF from: 3, 5, 8, 13, 21, 34, 55, 89, 144, 233 minutes. Custom mode lets you pick specific TFs.

Key finding: Full-consensus (9/9 agree) trades averaged $73.78 each vs $0.65 for low-agreement trades — a 113× per-trade difference.

🚀 Escape Mechanism

The core BD Method: when position is oversized and gets ANY profit, close the bulk and keep a small runner.

Progressive escape: Start at 70%, +10% per add above minimum. 2 adds=80%, 3=90%, 4+=98%.

Runner cannot add — prevents the escape-add infinite loop bug. Runner exits only via TP or Swing.

📊 Volume-Weighted Extension

Low volume overextension → enter sooner (likely to revert). High volume → wait longer (momentum may continue).

Formula: adjER = extRatio × (2.0 / (1.0 + volume / volMA50))

📈 Macro Bias EMA

200-bar EMA trend filter. Bull market (close > EMA): longs enter easier (×0.85 threshold), shorts harder (×1.2). Bear: reverse.

🔄 DCC Regime Stability

Coefficient of variation of leg amplitudes → coupling score (0 to 1). DCC ≥ 0.7 = stable, DCC < 0.4 = chaotic.

When ON: adjusts entry threshold — stable regime = lower threshold = more trades.

📐 Sqrt Compounding

When flat, scale base size: base × sqrt(equity / initialEquity). $10K→$20K = base ×1.41. Conservative, anti-fragile growth.
