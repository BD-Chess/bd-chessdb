Table Columns

Ver. & Era - The script version number and its architectural codename.
Exec. - Execution Paradigm (How the script handles system CPU threads).
Arch. Leap - The fundamental change in software engineering for that version.
Features - The mathematical or compression tools added to the engine.
Size - Final .8za file size in bytes.
Time Spent - Total wall-clock encoding time.

Execution Tags

Threaded Standard multiprocessing pool. Fast, but flies "blind".
Sequential Uses 1 core. Slowed down by AI learning feedback loops.
Decoupled Best of both worlds. Sequential fast-scan followed by highly optimized parallel encoding.

Terminology

MDL - Minimum Description Length. The arena where candidates fight for smallest byte size.
DCC - Dynamic Codec Control. A machine-learning approach to prune bad predictors.
L/R/M - Left, Right, and Mid. Scanning all 3 prevents missing hard-panned transients.
LPC - Linear Predictive Coding.
Note: Size and time for v1.2 are estimates. Final values will be updated when encoding completes.
