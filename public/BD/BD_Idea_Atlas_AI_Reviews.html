Updated score interpretationPosodobljena interpretacija ocen

What goes up

  • Concrete artifacts/code: now credibly in the mid/high 90s after TSP + NAS + DNA + 8Z + PiX + Flip4M + RouteSignal + Sudoku.
  • Test/arena discipline: now also mid/high 90s; multiple domains use controls, smoke tests, seeds, manifests, kill-tests, or benchmark logic.
  • Reproducibility potential: much stronger than W1 implied, because the code exists and several local tests pass.

What does not go up automatically

  • External validation: still low-to-moderate because LLM code review is not third-party human reproduction.
  • Public readiness: code must be packaged, documented, simplified, and linked from the website.
  • Hardware/physical proof: DGTE/HTH/MGHB/SORA still need bench data and physical tests.

Accepted criticisms after W2Sprejete kritike po W2

Credibility / proof

  • Publish one-command reproducibility bundles for the strongest code artifacts.
  • Open or package TSP, NAS, DNA/FASTA, 8Z image, PiX, RouteSignal, Flip4M, and Sudoku with expected outputs.
  • Keep LLM review separate from independent human reproduction.
  • Keep trading clearly labeled as research simulator / high-risk arena, not financial proof.
  • For physical devices, prioritize first cheap bench tests: HTH clear pipe, MGHB wave tank, DGTE crossover slice.

UX / claim hygiene

  • Add “What this demonstrates / What this does NOT prove” to every evidence pack.
  • Change public Flip4M proof-style wording from “proves” to “tests” or “playable DCC testbed”.
  • Add no-JS fallback summaries/screenshots for JS-heavy pages.
  • Use canonical links and keep archive out of scoring pages.
  • Make physical-device branch clearly first-class on the homepage.

Next updateNaslednja posodobitev

The next public upgrade should not be another generic LLM score. It should be the first reproducibility pack. My recommendation: start with 8Z-RP / TSP, then NAS, then DNA/FASTA. This will move the conversation from “LLMs think it is good” to “outsiders can run it.”

Naslednja javna nadgradnja naj ne bo še ena splošna LLM ocena. Naj bo prvi reproducibility pack. Moj predlog: začni z 8Z-RP / TSP, potem NAS, potem DNA/FASTA. To premakne pogovor iz “LLM-ji mislijo, da je dobro” v “zunanji ljudje lahko to zaženejo.”
