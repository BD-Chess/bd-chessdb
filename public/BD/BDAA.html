4. Reanchor je dvostopenjski dogodek: signal → revalidiran fill

  1. Ob phone-check closeu setup samo ustvari intent.
  2. Na naslednjem 1m open ponovno preveri: kdo je še loser, ali je setup še svež, ali je drift sprejemljiv, ali je impulse že preklical thesis, ali je account še equal-core in brez drugega rescuea.
  3. Količino ponovno izračunaj na dejanski fill ceni. Stale qty se ne sme slepo izvršiti.
  4. Če je minimum-sufficient add večji od risk/margin cap-a → NO ACTION.
  5. Če fill nastane, takoj deaktiviraj nezdružljiv winner conditional in takoj postavi exact-excess TP.
NO CHASE: če se je cena med signalom in naslednjim openom že vrnila, če loser ni več loser ali če je setup potekel, intent umre. Nova akcija zahteva nov dogodek.

5. Sizing: minimum-sufficient add, ne minimum target

Če je loserjev stari gap D bp in želiš po reanchorju doseči target po ugodnem premiku R bp, z majhnim profit-lockom g velja približno:

Total book multiple M ≈ D / (R − g)    ·    add multiple ≈ M − 1

Manjši target pomeni hitrejši možni rescue, vendar eksplozivno večji add. Zato je cilj najmanjši add, ki daje razumno dosegljiv target in prestane risk budget, ne najmanjši možni retrace.

Risk po času odsotnosti

max net-excess / wallet ≈ loss_budget × 10,000 / adverse_planning_bps

v0.1.2 uporablja kot raziskovalne planning proxyje približno 110 bp (5 min), 160 bp (15 min) in 285 bp (60 min). To niso garantirani tail boundi. Daljši možni čas brez telefona mora praviloma znižati dovoljen excess.

Trenutni live leaderji na W250k niso priporočilo za W250k in njihove G5/G10/G20 oznake niso net leverage. Long live extract prikazuje top absolutni PnL in zato sistematično favorizira velik wallet. Končni wallet frontier še ni znan.

Če je rescue intent ali rescue active, winner stop, ki bi lahko pustil velik naked book, mora biti preklican/zamrznjen. Ne dovoljuj latentne collision poti.

7. Exact-excess TP in pair reset sta jedro »surfing hedge«

Po loser addu pri ceni P1 se weighted average premakne proti trgu. Ko retrace doseže eksplicitni target, zapri samo excess. Originalni core ostane.

A = (q·P0 + d·P1)/(q+d)    →    po TP ostane q LONG @ P0 + q SHORT @ A

Ko sta quantity spet enaki, se price delta spet zaklene. Če je spread med averageoma dovolj velik, lahko realiziraš del profita brez smerne napovedi:

pair trim realized = h(P−L) + h(S−P) = h(S−L)
Current evidence podpira več zaporednih zaključenih ciklov: najboljši vidni STALL cell ima 14 reanchorjev, 14 exact-excess TP in 14 pair resetov ter konča kot COMPLETE_EQUAL_CORE.

10. Phone-check card — trenutna operativna verzija

A. Najprej stanje

Če RESCUE_ACTIVE ali DIRECTIONAL_HANDOFF:
  ne odpiraj novega nepovezanega setupa.
  Upravljaj obstoječi tail / TP / repair.

Če EQUAL_CORE in brez pending orderjev:
  nadaljuj na setup gate.

B. Setup gate

NO ACTION, če:
- samo outer-BB touch ali samo reentry
- impulse še pospešuje
- ni completed large outside-BB displacementa
- ni fresh extreme + stall/reversal/selektivnega potrjevanja
- setup je zamujen
- minimum-sufficient add presega risk/margin cap

REANCHOR INTENT, če:
- completed displacement je dovolj velik
- svež extreme je prisoten
- STALL / REVERSAL / SELECTIVE gate je veljaven
- continuation veto ne zahteva zavrnitve ali manjšega sizea

C. Na naslednjem open

REVALIDATE EVERYTHING.
Če loser/setup/size/risk ne držijo več → CANCEL.
Če držijo → fill minimum-sufficient qty → takoj exact-excess TP.

D. Po TP

Če qty spet equal:
  meri locked spread.
  pair trim/reset samo, če je spread dovolj velik.
  sicer NO ACTION.
Sleep rule: za dolg nenadzorovan interval ciljaj na equal qty, brez rescue excessa, brez pending reanchorja in brez winner stopa, ki bi lahko sam ustvaril velik naked book.

4. Reanchor is a two-stage event: signal → revalidated fill

  1. At the phone-check close, a setup only creates an intent.
  2. At the next 1m open, recheck who is still the loser, setup freshness, drift, impulse invalidation, equal-core state and absence of another rescue.
  3. Recompute quantity at the actual fill price. Never blindly execute stale quantity.
  4. If the minimum-sufficient add exceeds risk/margin caps → NO ACTION.
  5. If a fill occurs, disable any incompatible winner conditional and immediately place the exact-excess TP.
NO CHASE: if price already reverted before the next open, if the leg is no longer the loser, or if the setup expired, the intent dies. A new action requires a new event.

5. Sizing: minimum-sufficient add, not minimum target

If the old loser gap is D bp and the post-reanchor target requires an adverse-to-favorable move of R bp with small lock g:

Total book multiple M ≈ D / (R − g)    ·    add multiple ≈ M − 1

A smaller target can make rescue faster but makes the add explode. The objective is the smallest add that gives a reasonably reachable target and passes the risk budget, not the smallest possible retrace.

Risk by unattended horizon

max net-excess / wallet ≈ loss_budget × 10,000 / adverse_planning_bps

v0.1.2 uses research planning proxies around 110 bp (5 min), 160 bp (15 min), and 285 bp (60 min). These are not guaranteed tail bounds. A longer unattended horizon should generally reduce permitted excess.

Current live leaders at W250k are not a W250k recommendation, and G5/G10/G20 labels are not net leverage. The live summary ranks absolute PnL and therefore favors large wallets. The final wallet frontier is still unknown.

MAINLINE OFF A full winner-only exit converts a neutral book into directional handoff, so it is no longer used as the base profit-lock mechanism.

DEFAULT:
  winner_mode = NONE
  keep winner core open
  seek profit through loser reanchor + exact-excess TP + locked spread

PREFER BEFORE WINNER-ONLY EXIT:
  1. exact-excess TP

  3. partial coordinated winner action (challenger)

If a rescue intent is armed or rescue is active, any winner stop that could leave a large naked book must be cancelled/frozen. No latent collision path.

7. Exact-excess TP and pair reset are the core of the “surfing hedge”

After adding to the loser at P1, weighted average moves toward market. When retrace reaches the explicit target, close only the excess. Original core stays.

A = (q·P0 + d·P1)/(q+d)    →    after TP: q LONG @ P0 + q SHORT @ A

Once quantities are equal again, price delta re-locks. If spread between averages is large enough, realize part of it without directional prediction:

pair trim realized = h(P−L) + h(S−P) = h(S−L)
Current evidence includes repeated completed cycles: the strongest visible STALL cell has 14 reanchors, 14 exact-excess TPs and 14 pair resets, ending COMPLETE_EQUAL_CORE.

10. Phone-check card — current operational version

A. State first

If RESCUE_ACTIVE or DIRECTIONAL_HANDOFF:
  do not start a new unrelated setup.
  Manage existing tail / TP / repair first.

If EQUAL_CORE and no pending orders:
  proceed to the setup gate.

B. Setup gate

NO ACTION if:
- only outer-BB touch or only reentry
- impulse is still accelerating
- no completed large outside-BB displacement
- no fresh extreme + stall/reversal/selective confirmation
- setup was missed
- minimum-sufficient add exceeds risk/margin cap

REANCHOR INTENT if:
- completed displacement is large enough
- fresh extreme exists
- STALL / REVERSAL / SELECTIVE gate is valid
- continuation veto does not require rejection or smaller size

C. At the next open

REVALIDATE EVERYTHING.
If loser/setup/size/risk no longer hold → CANCEL.
If they hold → fill minimum-sufficient quantity → immediately place exact-excess TP.

D. After TP

If quantity is equal again:
  measure locked spread.
  pair trim/reset only when spread is large enough.
  otherwise NO ACTION.
Sleep rule: for a long unattended interval, aim for equal quantities, no rescue excess, no pending reanchor and no winner stop that can autonomously create a large naked book.
