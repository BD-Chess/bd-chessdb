# Nara4 mini — editorial pass

## Scope

Targeted consensus changes only. No image, audio, CSS, JavaScript, story architecture, central scenes, or artifact answer was replaced.

## Adopted changes

- Grounded Nara and Episode 01 now lead the index hierarchy.
- AC is defined as Absolute Consciousness at first public use.
- Illuminara is consistently identified as an original standalone parallel continuity; third-party experiments remain separate and non-commercial.
- Episode 02 navigation now includes Illuminara.
- Removed the public `Behind the story` explanatory appendices from Episodes 02 and 03.
- Reduced the most repetitive WATCH / AMBER / RED explanations in Episode 03 while preserving the posted thresholds, authority, stop rights, and causal sequence.
- Condensed one repeated artifact disclaimer into an evidence-log action.

## Deliberately unchanged

- All images and audio references.
- Nara and Illuminara core profiles beyond status/AC clarification.
- Episode 01 story text.
- Gate Seven, one-pump/one-minute, Miri, the ridge collapse, the key, the sphere, father mystery, and black-arc hook.
- CSS, JavaScript, image manifest, and filenames.

## Editorial principle

The pass removes explanation where scenes already carry the meaning. It does not redesign the project.
