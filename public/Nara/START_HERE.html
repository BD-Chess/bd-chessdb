Nara · local start page

Start here.

First extract the complete ZIP. The HTML pages need the neighbouring assets folder containing their styling and images.

  1. Right-click Nara_web3.zip.
  2. Choose Extract All...
  3. Open the extracted folder.
  4. Double-click OPEN_NARA.bat or index.html.
Open Nara after extraction

If this button does not open Nara, you are probably viewing this file from inside the ZIP. Extract everything first.
