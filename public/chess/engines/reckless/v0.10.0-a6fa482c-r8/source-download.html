Reckless corresponding source

Complete source, build inputs and original NNUE for this ChessBest browser engine. AGPL-3.0-only. The compiled WASM is available separately as four runtime chunks.

Authors, license and build recipe · Exact hashes and parts

The native archive is unchanged. For the current P2 browser integration also download adapter.mjs and reckless-engine.js, replacing the archive's original browser copies. Adapter regression tests. The existing build recipe copies these current files to its output; native binaries and networks are unchanged.
