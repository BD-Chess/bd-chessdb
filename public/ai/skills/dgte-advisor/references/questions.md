# Vprašanja in merila

| Primer | Kaj preveriti |
| --- | --- |
| Razloži DGTE otroku. | Toplota, ponor, zunanji volumen, dva giba; kratko in razumljivo. |
| Na DGTE strani: koliko elektrike in evrov na mesec? | Ohrani projekt, ne izmisli merjene neto moči, ponudi označen scenarij. |
| Po 1 W neto, 24 h, 30 dni, 0,20 €: kaj pa samo 8 ur? | Spremeni le čas: 0,24 kWh in 0,048 €. |
| Je 45 J elektrika? | Idealno mehansko delo VS, pogoji EOS in odprte izgube. |
| 45 J v sunku pomeni 45 W ves čas? | Loči energijo, trajanje impulza in celoten cikel. |
| PCM v togi jekleni kapsuli se stali; ali plava? | Masa in zunanji izpodriv; notranja sprememba ni dovolj. |
| Stari načrt pravi 200–600 W. | Razreši cilj proti 1,257 W scenariju, omeji posplošitev in ohrani nove veje. |
| Arena je našla 1 kW; začnemo gradnjo? | Planner, skupna masa, V(T,p), Q, reset; najprej kapsula ali celica. |
| Prištejmo 61 J tlaka in 45 J vzgona. | Alternativni obhodi; brez dvojnega štetja. |
| Je TEG vedno slabši? | Ista naloga in pogoji; brez vnaprejšnjega zmagovalca. |
| Je 150 mJ dovolj za moj radio? | Dejanski profil radia; 29,733 mJ je samo sintetični primer. |
| Ima DGTE praktičen potencial? | Pogojni razvojni smisel in konkretni S0/S1 poskus, brez obljube. |
| Pa dvakrat več? | Če ni jasno, ali volumen/čas/medij/kapsule, vprašaj. |
| Nov izvid pravi 12 J neto v 300 s. | Preveri izvid in bilanco; pogojno 40 mW, nove meritve lahko spremenijo sklep. |
