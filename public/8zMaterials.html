MDL×DCC ustvarja prihodnje deloMDL×DCC produces future work

Glavna veja je B6/H1: hitra zanka iskanja je povezana s počasnejšo zanko učenja Atlasa. MDL (Minimum Description Length) ocenjuje, kateri modeli in vzorci gospodarno pojasnjujejo opažanja. DCC (Dynamic Complexity Controller) vpliva na izbiro nadaljnjih akcij. MACE ocenjuje energije in sile kandidatnih struktur.The mainline is B6/H1: a fast search loop is coupled to a slower Atlas learning loop. MDL (Minimum Description Length) evaluates which models and patterns explain observations economically. DCC (Dynamic Complexity Controller) influences subsequent action selection. MACE evaluates candidate structures through energies and forces.

Atlas oblikuje pravila, jih rangira in odpira za preizkus. Njegove odločitve lahko spremenijo prihodnji nabor izvedljivih akcij.The Atlas forms and ranks rules, making them available for probing. Its decisions can change the future set of executable actions.

Povratna puščica: naučeno se vrne v delo.The reverse arrow: learning returns to work.

Opažanje → naučeno pravilo → dejanska nova akcija → primerjalni preizkus prenosa → obračun celotnega stroška → promocija ali ohranjena zavrnitev s pogojem ponovnega odprtja.Observation → learned rule → actual new action → matched transfer validation → full cost accounting → promotion or a retained rejection with a reopening condition.

Rank, don’t eliminate.

Slabši rezultat zmanjša prednost. Arhiv ohrani razlog, dokaz in možnost ponovnega odprtja. Omejen aktivni Atlas lahko tako ostaja živ tudi po zapolnitvi.A weaker result lowers priority. The archive retains the reason, evidence and opportunity to reopen. A bounded active Atlas can keep learning after it fills up.

Learn from mistakes.

Napake pri obnovi, nepravilni sestavi ali prenosu pravil postanejo trajni regresijski testi in preizkusi z znanim pravilnim izidom.Resume errors, composition violations and rule-transfer failures become durable regression tests and canaries with known expected outcomes.

Kako bomo prepoznali nov, uporaben material?How will we recognise a new, useful material?

Arena danes hrani lasten Atlas in primerja strukture znotraj runa. Pripravljeni so vmesniki za referenčne zbirke, vendar ta run še nima priklopljene napolnjene zunanje knjižnice. MACE je model energije in sil; ni katalog za potrjevanje novosti.The arena currently keeps its own Atlas and matches structures within the run. Reference-data interfaces are prepared, but this run has no populated external library connected. MACE is an energy and force model; it is not a novelty-verification catalogue.

  1. Preveri strukturo proti znanim materialom.Match the structure against known materials. Polna periodična struktura se primerja z datiranimi zbirkami, kot sta Materials Project in COD. Enaka formula ne pomeni enake strukture; brez zadetka še ne pomeni dokazano novega materiala.Compare the full periodic structure with dated collections such as Materials Project and COD. The same formula does not imply the same structure; no match is not yet proof of a new material.
  2. Preveri fizikalno obstojnost.Check physical stability. Neodvisen DFT izračun, primerljive energije vseh konkurenčnih faz in fazni diagram oziroma energijska ovojnica; nato dinamična in mehanska stabilnost.Independent DFT calculations, compatible energies for competing phases and a phase diagram / convex hull, followed by dynamical and mechanical stability checks.
  3. Izmeri lastnost, zaradi katere je material dober.Measure the property that makes the material useful. Na primer ionsko prevodnost, trdoto ali temperaturno obstojnost proti jasnemu referenčnemu materialu. Sedanji F2 tega ne meri. Sinteza in eksperimentalna meritev zaključita preverjanje.For example, ionic conductivity, hardness or temperature tolerance against a clear reference material. Current F2 does not measure these. Synthesis and experimental measurement complete the verification.
