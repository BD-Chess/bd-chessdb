AI8 Native Drive

AI8 Native Drive is BD's private desktop integration between the AI8 workspace and Google Drive. It runs on the owner's Linux machine using rclone and the Desktop OAuth client AI8 Razer — rclone. There is no public signup or multi-user service.

The current integration:

  • checks a designated AI8 coordination folder for notice metadata and routing headers;
  • keeps local cursors, delivery records and diagnostic receipts for continuity;
  • reads and updates a designated Drive heartbeat file with selected host and service status.

The app requests the full Google Drive scope, https://www.googleapis.com/auth/drive, which permits viewing and managing all files in the authorized account. Current background routines use narrower, designated AI8 routes and files; those code restrictions do not narrow the OAuth permission itself. See Google's scope description.

Drive polling and heartbeat code do not call a model or run an arena. A watcher transition can queue a fixed local status prompt to an existing CLI agent session. Owner-authorized assistant review can separately read files and send selected context to the assistant provider.

This native OAuth client is separate from Google Drive connections inside Codex, Claude or other connected plugins. Those connections have their own authorization and data practices.
