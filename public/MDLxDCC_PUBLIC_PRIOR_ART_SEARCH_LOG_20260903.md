**Date / cutoff:** 2026-09-03  
**Status:** public working note / correction-open / not a patentability or freedom-to-operate opinion

**Human architecture and origin:** Bojan Dobrečevič (BD)  
**Development context:** BD × multiple AI collaborators

## 1. Exact object being searched for

The priority question is not whether compression, MDL, adaptive control, program generation, routing, meta-learning or recursive optimization existed before 8Z–MDL×DCC. They did.

The searched object is a practical architecture containing all six properties together:

1. **Alternative-representation generation** — the system can create or compare different descriptive languages, mathematical generators, operators, models or problem representations.
2. **Full-cost MDL selection** — selection accounts for the complete description, including model, residual, decoder, exceptions and declared execution/integration cost rather than one attractive score.
3. **Dynamic stable-but-reopenable governance** — a controller allocates search resources, holds productive focus, changes scale or method, and can reopen previously weak paths when evidence changes.
4. **Multi-level recursion** — the same grammar operates at more than one scale or level of search.
5. **Governor self-selection** — sensors, control laws, polarities, topologies or governors can compete and lose under the same selection principle.
6. **Measured heterogeneous-domain transfer** — the same architectural grammar is implemented and measured across substantially different problem families rather than asserted by analogy alone.

## 2. Assurance boundary

This note records the bounded candidate set and comparison disclosed by index v0.2.5. It does **not** establish that every paper, patent, repository, private laboratory or unpublished garage project has been searched. Absence from this note is not evidence of absence.

The claim is therefore:

> In the public systems examined through 3 September 2026, no earlier practical system was identified that matched the complete six-part conjunction above.

The claim is open to immediate correction by a dated public source showing the full conjunction before the disclosed 8Z–MDL×DCC lineage.

- AutoML-Zero, learned optimizers and other meta-optimization systems;
- hierarchical routing / Mixture-of-Experts and adaptive-computation controllers.

The purpose of the next rerun is not to make the six-part conjunction harder to attack by definition. It is to identify which of these neighbours already contain load-bearing parts of the claimed wiring, and to narrow the novelty claim if necessary.

## 6. Defeat condition for the priority claim

The bounded priority claim should be withdrawn or narrowed if a dated earlier public system is found that practically implements all six properties, not merely adjacent terminology.

A partial match should be added to the neighbour matrix and may narrow the claimed novelty to the remaining architectural delta.

## 7. Relationship to evidence of effectiveness

Historical priority and empirical value are separate questions.

Even if 8Z–MDL×DCC is the first publicly documented system of this specific kind, it can still fail empirically against simpler controllers, stronger baselines, held-out tasks or full-cost accounting.

Even if an earlier full match is found, the current implementations and cross-domain evidence may still have independent engineering value.
