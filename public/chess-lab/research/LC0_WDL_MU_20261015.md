# LCZero display scale and compact-network assessment

Date: 2026-10-15. Scope: ChessBest LAB display conversion, not engine search.

The displayed neural pawn score now uses Lc0 v0.32.1's `WDL_mu` conversion,
including its float32 FastLog/FastLogistic and extreme-probability fallback.
Contempt and WDL rescaling are disabled. Original Q, root/White WDL, visits,
PV order, engine identity and exported evidence stay native. Missing, invalid
or inconsistent WDL uses an explicitly labelled Q fallback. Approximate pawn
values are not fed back into search, DCC ranking, or same-square Q ordering.

Deep's persistent, collapsed **Score details · W/D/L** shows each variation's
win/draw/loss estimates for White, Q, conversion and approximate cp. Its open
state and scroll position survive streamed updates. Cards, overlays, candidate
lists and Deep all use the same conversion. Model probabilities describe the
network, not calibrated real-world guarantees.

## Independent numerical verification

Reference: `LeelaChessZero/lc0@fd71a2d921b689c5f479d3227c3806c8e272d9c5`
(v0.32.1), `src/search/classic/search.cc` and `src/utils/fastmath.h`.

`tools/generate-lc0-wdlmu-reference.py` hash-verifies upstream source and
compiles its original WDLRescale function into a standalone C++ reference.
The checked-in fixture has 169 inputs, including 30 actual native Maia WDL
samples and a sweep over draw rates, both colors and numeric boundaries.
165 reference outputs match to the exact integer cp in this run. The unit
gate permits at most 1 cp for compiler/float differences.

Four extremely broad distributions make upstream's approximate logarithm
produce mu with the opposite sign to Q. Those are deliberately guarded:
the display uses the native Q fallback and labels it `unstable WDL`.
The fixture preserves upstream's original outputs; it does not silently
rewrite them. Invalid Q remains unavailable, and neural endpoints never
invent a mating distance or tablebase result.

Reproduce the fixture (Python 3 and g++):

```sh
python tools/generate-lc0-wdlmu-reference.py --output public/chess-lab/research/fixtures/lc0-wdlmu-reference.json
```

## Compact analysis-network candidates

This is a source/architecture assessment, not a browser strength benchmark.
The current Maia 1900 is human-trained, 64 filters × 6 SE blocks, with a
classical 112-plane input and WDL/convolution heads. A stronger candidate
must first pass encoder/output parity, legal-policy mapping, single-thread
WASM latency, memory, cancellation and physical-device checks.

| Priority | Candidate | Evidence and practical consequence |
| --- | --- | --- |
| 1 | J104 / T74 family, 128 × 10 | Official legacy list; J104's author describes T70 training with value repair. A suitable first compact analysis candidate. Trunk work scales roughly 6.7× versus 64 × 6, before input/head costs; actual speed and current tensor/head compatibility remain unmeasured. |
| 2 | T1-256x10-distilled-swa-2432500 | Officially listed small GPU/CPU net, about 30–40 MB of weights. Transformer architecture requires a separate encoder/policy/output compatibility check and a substantially larger runtime budget. |
| 3 | Little Demon 2, 128 × 10 | Official legacy entry; published archive is 6,366,549 bytes. Actual value-head format, conversion and performance remain unverified, so it is not a verified WDL replacement. |

Direct retrieval of the official `744706.pb.gz` and `LD2.pb.gz` files returned
HTTP 403 in this environment. No weights, inference, strength or device
memory measurements are claimed for them. Maia is retained in this release;
network replacement remains a separate, unverified candidate.
